# Mix Web 部署工具

macOS 和 Windows 的 JS 管理共用 `Shared/WebUI` 中的 HTML/CSS 页面。Mac 通过系统 WKWebView 接入既有 Swift 本地功能，支持本地 JS 打包、下载、归档、搜索、安装与备份恢复，也保留通过 Jumpserver 管理服务器 Git 分支的功能。Windows 版为独立的 JS 本地管理工具，仅包含本地操作，不包含服务器管理。

## 安全原则

- PEM 私钥始终保留在应用外部，应用只保存文件路径。
- 分支名、SSH 地址和项目路径均经过白名单校验。
- 服务器工作区存在未提交修改时，停止切换分支。
- 使用 `git pull --ff-only`，不自动制造合并提交。
- 使用 `sudo -n`，应用不会请求或保存远程 sudo 密码。
- 日志不转发 SSH 命令、登录横幅、资产菜单和 Shell 提示符；连接字段与常见地址、路径会再次脱敏。复制按钮复制的是同一份脱敏日志。

## 构建

当前 Mac 已安装 Swift Command Line Tools，无需完整 Xcode 即可构建：

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
```

生成结果：

```text
dist/Mix Web 部署工具.app
```

## 首次配置

- Jumpserver：填写团队提供的 SSH 主机和端口。
- SSH 用户：填写个人的 Jumpserver 用户名。
- 项目目录：填写服务器上的 Git 仓库绝对路径，例如 `/path/to/project`。
- Jumpserver 菜单：按照实际交互流程填写两次菜单选项。
- PEM：通过文件选择器指定当前 Mac 上的私钥文件。

仓库不包含真实连接信息或私钥。所有配置都在应用界面填写，并保存在当前 Mac 用户的 `UserDefaults` 中。

配置完整时，“连接设置”默认折叠，点击“展开修改”可以继续修改主机、用户、端口、私钥路径和项目目录。首次使用或配置失效时会自动展开。执行期间暂时禁用字段，避免本次操作的目标发生变化。更新应用保留原有本机配置。

修改连接后会清空旧服务器的分支列表；修改分支或连接后会清除旧成功状态。

## 使用顺序

1. 点击“检查连接”。
2. 点击“选择分支”打开搜索弹窗。列表为空时可在弹窗内“加载分支”或“同步远程”，也可在主界面直接输入已知分支。
3. 点击“切换并拉取”，确认后执行。

“刷新分支”只读取服务器上现有的 `origin` 分支记录，不执行 `fetch`；仍需要建立 SSH 连接并进入 Jumpserver。若找不到新建分支，点击“同步远程”，执行 `git fetch --prune origin` 后重新读取列表。两种操作均不切换工作区分支。

“选择分支”入口始终可打开；执行操作期间弹窗显示当前进度，完成后允许选择。分支列表仅保存在本次运行的内存中，重启应用后需要重新加载；加载失败时弹窗提供错误说明和重试入口。

分支读取使用基础 `%(refname)` 格式，避免依赖服务器 Git 的 `strip` 格式修饰符。读取失败会区分非 Git 仓库、sudo 授权、仓库属主及文件权限等常见原因；未识别的错误保留退出码，不显示包含内部信息的原始诊断。工具不会自动修改服务器权限或 Git 信任配置。

“切换并拉取”的远程操作顺序为：

```text
git fetch --prune origin
git status --porcelain
git checkout <branch>
git pull --ff-only origin <branch>
```

执行区按实际操作显示阶段；失败会停留在对应步骤，成功时显示完成时间和耗时，切换并拉取还会显示目标分支和提交号。“停止”会断开连接，已经执行的远程步骤不会撤销；请核对服务器状态后再继续。

## JS 本地管理（0.6.0）

应用默认进入“JS 本地管理”，原有远程操作放在“服务器分支管理”页。JS 管理只修改本机文件，不上传 JS，不读取浏览器登录信息，不访问后台新增或修改接口。网络请求仅用于下载用户粘贴的版本站点链接。

### 添加 JS

- **本地打包**：选择 `mix_client` 仓库根目录，填写备注，点击“打包保存”。使用当前分支和未提交修改执行 `npm run buildLb`，校验产物并保存独立副本，不安装。也可点击“打包并安装”，归档后再更新目标文件。只打包不要求配置有效的 AdsPower 目标目录。
- **链接下载**：在后台查找所需版本并复制完整下载链接，粘贴到工具，填写备注，点击“下载并保存”。支持 `https://version.adspower.net/.../版本号_main.min.js<MD5>`，必须保留链接末尾的 MD5。也可手动填写预期 MD5。只使用 GET，独立会话不发送浏览器 Cookie 或认证信息；拒绝跨域或非 HTTPS 跳转。下载不自动安装。
- **导入文件**：选择已有的完整主 JS，填写备注，校验后保存到本地库；不执行 JS。

同版本号、相同内容的多次打包或导入也会保留独立记录，记录版本、备注、来源、时间、分支（本地打包）、MD5 和 SHA-256。打包前暂存旧主文件，失败时恢复，避免误用旧产物；历史版本不会被同名新产物覆盖。支持常见 Homebrew 路径与 nvm default Node.js，打包超时为 15 分钟。

### 搜索与安装

“本地 JS 历史”支持按版本、备注、文件名和分支搜索；选中记录后可以修改版本名称和备注。先核对“目标 lib”目录，再点击“安装选中版本”。

安装前检查归档文件的 JS 语法和 SHA-256，将原 `main.min.js` 复制为同目录 `main.min.js.backup-时间-随机编号` 并保存备份记录，再以同目录临时文件原子替换目标。校验失败或取消时不会执行替换。成功替换后提示安装完成，重新启动 AdsPower 后生效。

“备份与恢复”只显示属于当前目标目录的备份，选择后可恢复。恢复前同样备份当前文件，保留可撤回的路径。备份文件丢失、被修改或属于其他目标时停止恢复，不强制覆盖。

### 本地数据与校验

默认库目录为 `~/Library/Application Support/MixWebDeploy/js-library`。归档副本保存在 `files/<UUID>/main.min.js`，索引 `index.json` 保存本地备注、版本和备份位置。配置与旧版保持兼容，仍保存在当前用户的偏好设置中。它们不包含在 Git 仓库或应用安装包内。

JS 文件必须为非空普通 UTF-8 文件，上限 100 MB；通过 JavaScriptCore 仅检查语法，不运行脚本。网页、错误响应、无效语法和校验值不匹配都会停止归档或安装。下载链接没有 MD5 且未手动填写时，只执行语法检查并计算本地校验值，不代表已验证发布方的 MD5。下载超时为 120 秒，支持停止。操作日志进行地址和路径脱敏。

构建期间使用项目内 `.ads-work-build.lock` 避免并发构建；应用异常退出后若锁仍存在，请先确认没有构建进程，再删除该锁文件。本地 JS 库使用文件锁避免多个窗口同时更新索引。操作进行时暂时禁止启动其他本地或远程任务。

Windows x64 版使用本地 HTML/CSS + WebView2 界面，详见 [Windows 使用与构建说明](windows/README.md)。默认项目目录为 `C:\install\mix_client`，目标 lib 使用当前用户 `%APPDATA%\adspower_global\cwd_global\lib`，两者均可在界面修改并保存。发布 ZIP 位于 `dist/AdsWork-JS-Manager-Windows-x64-0.6.0.zip`，完整解压后运行 `AdsWorkJsManager.exe`；自带 .NET 运行环境，界面另需 WebView2 Runtime。缺少时可通过随包提供的微软官方引导程序安装。仅本地打包功能需要 Node/npm、Git 和项目依赖。

## 0.6.0 共用 HTML 界面

Mac 的 JS 本地管理改用与 Windows 相同的 HTML 页面，统一圆角卡片、分段按钮、输入框与历史列表，支持窄窗口、空历史和运行状态显示。“文件信息与校验值”的箭头与文字居中，并与编辑框左侧对齐。按钮按压、来源滑块和内容切换、文件详情、备份、日志展开收起、备份下拉菜单与状态提示均有短过渡；遵循系统“减少动态效果”设置，菜单支持方向键、Home/End、Enter 和 Escape。

两端只维护 `Shared/WebUI` 一份页面。页面随应用打包，不从网络加载 UI 资源；本地消息接口限制固定页面来源及操作白名单，不提供任意命令执行接口。Mac 使用系统自带 WebKit，无需 Electron 或额外安装网页运行环境。Windows 继续使用 WebView2。

功能图标统一使用 Lucide（`lucide-static` 1.58.0），仅将实际使用的 19 个 SVG 收录到共用的 `Shared/WebUI/icons.svg`，两页按需引用同一份资源。统一使用 24 × 24 画布、2 单位笔画和圆角端点，常规显示尺寸为 16px；装饰图标不重复进入屏幕阅读器。蓝色盒子 Logo 保留。上游完整许可证见 `Shared/WebUI/lucide.LICENSE.txt`，随 Mac 应用资源分发，Windows 构建时同时复制到包内 `Licenses` 目录。图标无需联网或额外的运行时依赖。

Mac 的路径配置、本地历史和备份沿用原存储位置；服务器分支管理也使用 HTML，复用同一套样式与动画，入口位于窗口顶部工作区切换。连接表单自动保存、分支搜索弹窗、运行阶段和脱敏日志继续调用原有 Swift 核心；切换并拉取保留原生确认弹窗。该页面只包含在 Mac 版，Windows 仍仅提供 JS 本地管理。新版包为 `dist/Mix Web 部署工具-0.6.0.zip`（Apple Silicon）。

## 本地验证

```bash
zsh scripts/check.sh
```

自检使用临时本地 Git 仓库、内存配置和模拟交互终端，覆盖生产分支命令、格式兼容性模拟、嵌套分支名、分段 UTF-8 输出、日志脱敏、刷新跳过 fetch、远程同步、空列表、错误分类、工作区有修改、拉取失败、完成标记及停止行为。还会通过临时 Node.js 项目执行真实 `npm run buildLb`，验证带空格路径、同名及相同内容产物、备份、历史产物恢复、构建失败、产物缺失或歧义、分支变化、停止子进程、超时及构建锁。不会启动真实 SSH、执行真实远程 Git，或访问用户私钥、实际 AdsPower lib 与应用配置。

首次使用建议只执行“检查连接”。若 Jumpserver 菜单流程发生变化，可根据当前阶段和错误提示检查连接配置。

JS 库自检还覆盖独立历史、备注搜索与持久化、安装恢复、历史或备份篡改、错误内容、文件锁；通过离线 URLProtocol 验证下载地址与 MD5、GET、无登录信息、HTTP 错误、取消及界面模型完整流程。


Mac 网页消息通道检查需要在已登录的桌面会话中运行：

```bash
zsh scripts/check-web.sh
```

它使用真实 WKWebView 和临时 JS 库，检查路径读取、来源切换、备注持久化、安装备份、恢复、下拉选择、宽窄窗口、箭头对齐和导航限制，输出 `.build/mac-web-report` 中的截图与报告，不修改实际 AdsPower 文件。界面与动画检查及本轮结果见 [0.6.0 验证记录](docs/ui-0.6.0/README.md)。


服务器页面离线验证：`zsh scripts/check-remote-web.sh`。使用真实 WKWebView、内存配置、临时假 PEM 与 Expect 模拟服务器，检查配置保存、分支搜索回填、确认入口、加载、停止和日志；不连接真实服务器。截图和报告位于 `.build/remote-web-report`。
